    Our Commitment

    NextStep is committed to ensuring digital accessibility for people with disabilities. We believe civic engagement should be available to everyone in the Boca Raton community, regardless of ability. We continually improve the user experience for all users and apply relevant accessibility standards.

    Conformance Status

    We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. These guidelines explain how to make web content more accessible to people with disabilities. Our current accessibility features include:

    • Semantic HTML structure with proper heading hierarchy
    • ARIA labels on interactive elements (buttons, navigation, forms)
    • Keyboard navigability throughout the site
    • Sufficient color contrast ratios for text readability
    • Alt text on all meaningful images
    • Dark mode support for users with light sensitivity
    • Responsive design that works on all screen sizes and devices
    • Focus indicators for keyboard users

    Known Limitations

    While we strive for full accessibility, some areas are still being improved:

    • The interactive map may have limited screen reader support — we are working on an accessible text-based alternative
    • Some older embedded content (YouTube video on the homepage) may not be fully controllable by keyboard
    • The Compass AI chatbot is actively being tested for screen reader compatibility
    We are actively working to address these limitations and appreciate your patience.

    Assistive Technologies Supported

    NextStep is designed to be compatible with the following assistive technologies:

    • Screen readers (NVDA, JAWS, VoiceOver, TalkBack)
    • Browser zoom up to 200% without loss of content or functionality
    • Keyboard-only navigation
    • High contrast display modes
    • Voice control software

    Text and Visual Accessibility

    • Font size: Text can be resized using browser controls without breaking the layout
    • Color: We do not rely on color alone to convey information
    • Dark mode: A dark theme is available via the toggle in the navigation bar
    • Spacing: Adequate spacing between interactive elements to aid users with motor impairments

    Forms and Interactive Elements

    All forms on NextStep (contact, login, signup, newsletter) include:

    • Clearly labeled input fields
    • Error messages that identify the issue and suggest corrections
    • Required field indicators
    • Sufficient click/tap target sizes

    Feedback and Contact

    We welcome feedback on the accessibility of NextStep. If you experience any barriers or have suggestions for improvement, please contact us:

    Email: nextstep.civic@gmail.com

    We aim to respond to accessibility feedback within 5 business days. If you need information in an alternative format, please let us know and we will do our best to accommodate your request.

    Ongoing Efforts

    Accessibility at NextStep is an ongoing effort. We are committed to:

    • Regular accessibility audits of new and existing features
    • Training team members on accessibility best practices
    • Including accessibility requirements in our development process
    • Listening to feedback from users with disabilities
